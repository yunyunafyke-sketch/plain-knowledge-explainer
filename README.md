# 通俗知识讲解器

一个面向中文学习者的 Codex Skill，用官方资料建立正确的知识顺序，再用通俗中文把技术概念、理论和文档内容讲清楚、讲完整。

它不仅回答“这是什么”，还会把知识落到实际使用：解释核心原理、说明适用场景，并提供从准备、配置到验证的完整最小实践。

## 适用场景

- 用大白话解释技术概念、理论知识或复杂文档
- 跟随官方文档学习框架、产品或 API
- 将理论知识整理为可复习的中文 Markdown 笔记
- 为初学者准备带中文注释、可运行的最小示例

例如：

> “讲明白 Docker 是什么，并给我一个能跑起来的例子。”
>
> “按官方文档的顺序带我学习 Spring Boot。”
>
> “把这篇技术资料整理成学习笔记。”

## 核心特点

### 以官方资料为准

当主题存在官方教程或官方文档时，技能会优先阅读一手资料，并按照其前置依赖和概念顺序组织内容；类比只用于帮助理解，不替代正式定义。

### 先理解，再动手

默认采用“理论 → 实践”的结构：

1. 用一句话建立整体认知
2. 解释核心概念与必要原理
3. 说明可以用来做什么
4. 给出从环境、配置、代码、启动到验证的完整实践
5. 用简短要点帮助复习和记忆

### 示例真正可用

涉及代码时，示例会明确文件位置、依赖、输入输出、运行命令与预期结果。Java、后端和配置类示例默认包含中文注释，帮助读者理解“为什么这样写”。

### 重视笔记阅读体验

输出默认适配 Markdown 阅读：短段落、清晰标题、必要的表格和提示框。复杂流程可使用 Mermaid 图示；Obsidian / Quartz 知识库场景还会维护相关链接与必要的元数据。

## 使用方式

将本仓库作为 Codex Skill 安装或放入本地 Skills 目录后，直接描述你的学习目标即可：

```text
用大白话讲明白 Redis，并给我一个 Java 的完整实践。
```

```text
根据这份官方文档，按学习顺序讲解这个 API。
```

```text
把下面的内容整理成一篇 Markdown 学习笔记。
```

默认会先在对话中完成讲解，再在写入前询问笔记的准确保存路径；如果不需要文件，可明确说明“不要生成笔记”。

## 输出内容

典型输出会包含：

- 一句话理解
- 核心概念
- 工作原理
- 前置准备
- 常见用途
- 完整实践：配置、代码、启动与验证
- 常见问题或边界说明
- 总结与参考资料

对于版本、API 行为、产品政策、价格、法律、医疗、金融等可能变化或高风险的信息，技能会优先查证最新的一手资料，并标注适用时间或版本。

## 设计原则

- 不用术语堆砌代替解释
- 不把片段代码伪装成完整实践
- 不凭空补全用户未提供的具体事实
- 不为了“全面”加入与目标无关的背景
- 将已确认事实、帮助理解的类比和待确认信息明确区分
